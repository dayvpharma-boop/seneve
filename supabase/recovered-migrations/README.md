# Migrations récupérées du registre Supabase

Ces fichiers sont des copies des corps SQL enregistrés dans `supabase_migrations.schema_migrations` du projet de test `seneve-test`, récupérées en lecture seule le 6 novembre 2026. Les commentaires initiaux de provenance ont été ajoutés localement ; le corps SQL est la valeur stockée dans l'unique élément `statements` de chaque entrée.

Les deux entrées n'ont pas de valeur de retour arrière (`rollback` est nul). Elles n'existent pas dans l'historique de production. Leur présence ici documente leur source et ne les rend ni sûres à rejouer, ni nécessaires à appliquer en production. Toute utilisation exige de comparer la définition actuelle de chaque fonction dans les deux projets, de préparer une sauvegarde restaurable et un retour arrière vérifié.
