# Accès aux rappels web — 29 octobre 2026

Le bloc « Mes rappels » est placé dans Aujourd’hui, avant le calendrier et la journée. Il donne accès aux notifications du téléphone dans Profil, au choix des habitudes et des horaires dans Mes réglages pour l’inscription courante, et au calendrier du téléphone. Les liens conservent la langue et l’inscription concernée.

Les ancres ouvrent le calendrier et positionnent les rubriques chargées de façon asynchrone. Aucune notification n’est activée automatiquement et aucun réglage serveur n’est modifié. Les notifications web nécessitent Internet ; le calendrier reste une copie à importer et vérifier, sans synchronisation automatique. Le prototype Android est hors périmètre.

Validation : 11 tests ciblés existants réussis pour les rappels d’habitudes et l’export calendrier ; TypeScript et contrôles GitHub ; vérification visuelle après déploiement. Cache du site renouvelé.
